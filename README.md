## 🤝 Zhalslar 介绍

一个人类，会写很多有趣且实用的插件，目前已上架 50+ 个 AstrBot 插件。

## 📦 特性与安装

- 自动化捆绑安装：安装本插件后，Bot 会自动检测并静默安装配置列表中的全部 Zhalslar 插件。
- 动态管理：支持在配置文件中自定义增删需要捆绑的插件仓库地址。
- 一键检查更新：提供管理员指令支持手动触发安装和状态查看。

### 安装方法

- 在 AstrBot 插件市场中搜索 `astrbot_plugin_zhalslar` 安装，或直接输入仓库地址安装。

## ⚙️ 配置说明

在 AstrBot 面板的插件配置中可自定义以下项：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `auto_install_on_startup` | bool | `true` | Bot 启动时是否自动检查并安装未安装的捆绑插件 |
| `bundle_plugins` | list | 默认包含全套插件 | 捆绑插件的 Git 仓库 URL 列表 |

## ⌨️ 使用说明

| 命令 | 说明 | 权限 |
| :--- | :--- | :--- |
| `zsl install` | 一键检查并安装所有缺失的捆绑插件 | 管理员 |
| `zsl list` | 查看捆绑插件列表及当前安装状态 | 管理员 |
